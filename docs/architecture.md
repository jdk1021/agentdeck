# Architecture

```
AgentDeck.app/Contents
├── MacOS/AgentDeckApp      SwiftUI menu bar app (LSUIElement)
├── MacOS/agentdeck         CLI (same core; the app launches it in Terminal for sign-ins and sessions)
└── Resources
    ├── Runtime/            collector payload generated by scripts/prepare-runtime.py
    │   ├── bin/agentdeck-collect-<id>   23 collectors
    │   ├── lib/collectors.py            shared readers, billing attribution, caches
    │   ├── lib/agentdeck_macos.py       macOS Keychain adapters (read-only)
    │   ├── project-settings.py          account settings projection
    │   ├── python/                      pinned CPython 3.14 (python-build-standalone)
    │   └── tools/rg                     pinned ripgrep
    ├── ProviderIcons/  AppIcon.icns  Licenses/
```

The executables are named `AgentDeckApp` and `agentdeck` on purpose: the default macOS file system is
case-insensitive, so `AgentDeck` and `agentdeck` would be the same file. `package-app.py` refuses to
build a bundle where they collide and checks that the bundled CLI really is the CLI.

## Swift packages (`Sources/`)

| Module | Responsibility |
|---|---|
| `AgentDeckCore/Models.swift` | Collector JSON kept as `JSONValue` (unknown fields survive), limits, account registry, settings, provider inventory |
| `Storage.swift` | App directory `~/Library/Application Support/AgentDeck` (override `AGENTDECK_HOME`), `flock` per file, atomic writes + `fsync`, `.previous` backups, restore |
| `Runtime.swift` | Process runner: own process group via `posix_spawn`, concurrent stdout/stderr, timeout, group termination; CLI discovery (mise first, then common paths, wrappers skipped); runtime discovery |
| `Collectors.swift` | Runs collectors 4 at a time, keeps the last good record on failure (`collectorFailed`, `limitsStale`), applies switching, single-step refresh planner |
| `SwitchPolicy.swift` | Threshold switching (see below) |
| `Accounts.swift` | Registry for Claude/Codex/Grok, account homes, sign-in completion, removal/recovery, launch environment, settings re-sync |
| `Integration.swift` | App-owned Keychain keys, zsh marked block, wrapper recursion guard, Terminal `.command` files, `execve` launch |
| `UsageSync.swift` | Optional usage-only export and cross-device aggregation |
| `AgentDeckApp/` | SwiftUI panel, dashboard, settings, demo mode, provider artwork, file watchers |
| `AgentDeckCLI/` | `agentdeck` commands |

## Why the collectors stay in Python

The upstream collectors encode a lot of hard-won detail: quota endpoints, how every harness (pi, omp,
OpenCode, Claude Code custom endpoints, Codex routes, …) bills a provider, fork and message
de-duplication, caches and stale handling. Rewriting them would lose fidelity and make upstream fixes
hard to follow. AgentDeck therefore ships them nearly unchanged (named, audited patches only) with a pinned
interpreter, and keeps everything user-facing — UI, accounts, process selection, scheduling — in Swift.

## Refresh

- Full refresh: every enabled collector; interval 30 s–60 min (default 15 min).
- Short passes: when a provider asks to retry after a transport error (30 s), or a multi-account
  provider is within 15 points of its threshold (limits only, every 3 min). `RefreshSchedule.step`
  issues exactly one refresh per wake-up and turns the next wake-up into a full refresh once the regular
  interval is due, so short passes never add a duplicate refresh.
- Manual refresh passes `--force` (bypasses collector caches).
- The app watches the `accounts/` and `usage/` folders, so CLI sign-ins and changes made by
  `agentdeck` appear immediately.

## Switching policy

Applies to Claude Code, Codex and Grok when more than one account is registered.

1. The current account's highest window level must be at or above the threshold (default 95%).
2. Candidates must be signed in, have a successful measurement younger than 30 minutes, not be stale,
   and be below the threshold.
3. Ranking: accounts more than 15 points below the threshold first, then lower usage, then the earliest
   reset, then ID.
4. Manual mode suggests (notification); automatic mode selects for new sessions. A 180 s cooldown and
   alert de-duplication prevent oscillation.
5. If every account is at the threshold, the current account stays and the earliest reset is reported.

Expired windows count as 0%. Missing, stale or failed measurements never count as 0%.

## Process safety

Collectors run in their own process group. On timeout (110 s), or when a finished collector leaves
descendants holding its output open, only that group is terminated. The user's shells and agent sessions
are never signalled. `agentdeck run` replaces itself with the agent (`execve`), so the agent's lifetime is
independent of AgentDeck.
