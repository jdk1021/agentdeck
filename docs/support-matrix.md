Baseline: v4.5.0, commit `ac2690cd7be4f47e4a255f5e2e78d904d436b068`.
Source repository ID: [994093166](https://api.github.com/repositories/994093166).
Latest stable checked 2026-11-13: v4.5.0. No later stable patches were cherry-picked.

This is the implementation and release checklist. The 23 collectors were enumerated from executable source, not a hand-curated product list. `upstream-inventory.json` keeps each original content SHA-256 before mechanical renaming. Imported source filenames and identifiers use AgentDeck naming.

**Verification:** F = offline fixture parsing, quota/cache/error cases and provider attribution on macOS. L = successful real authenticated limit query. A = real app/package launch. Authentication requiring another person's subscription cannot be certified by fixtures. Live results are recorded in `validation.md`; F alone never means a live service was tested.

All rows implement the baseline collector, including its full shared routing readers, rather than empty adapters. Individual support is intentionally different: some have limits, some balances, some only statistics. Multi-account support is limited to the three providers that implement it in the baseline. “No” means no upstream support, not a missing AgentDeck adapter.

## Shared acceptance rules

- `Runtime/bin/agentdeck-collect-*` must exactly equal the inventory: 23 IDs, no omitted/new unknown collector. `scripts/audit.py` enforces equality.
- Shared billing classification includes pi and omp profiles, both generations of OpenCode stores, Claude Code custom endpoints, Codex provider/base-URL routes, MiniMax Code, DeepSeek Harness, Kimchi, Qwen, Hermes and Vibe. Forks, repeated message IDs, compactions, nested roots and caches preserve the baseline partition rules.
- OpenCode Zen usage and OpenCode Go quotas are distinct. No Go plan means local usage alone. Cloud-tagged Ollama models bill Ollama Cloud; self-hosted models bill `local`.
- A failed or stale probe never becomes zero usage. Reset windows follow upstream semantics; automatic selection requires fresh successful observations for the account.
- API-key/unsupported plans never get invented subscription limits. Cursor/Grok Bot use private dashboard RPCs; Claude, Google and several billing adapters also depend on service-specific endpoints. Changes can require adapter updates.
- The original Copilot local fallback is an estimate, not an authoritative quota. The UI explicitly exposes the source text/estimate warning. DeepSeek funded-versus-spent and Fireworks configured funding are also labeled by the baseline record rather than represented as live ledger data.
- Actual provider login requires the provider CLI or a user-supplied key. AgentDeck never silently installs an agent CLI.
